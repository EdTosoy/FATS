## Root cause, including semantic diagnosis

Pre-fix case 02 supplied the following resume context: **“Education: BS Information Technology. No JavaScript or React project listed.”** The job asked for **“HTML, CSS and JavaScript projects required.”** and **“React experience preferred.”** A separate sentence documented a completed HTML/CSS school portfolio.

Full-context review supports `partial` for the compound requirement and `undocumented` for React. The labels were not assumed correct from exact citation matching. The negative React statement describes what is not documented and does not establish React experience. The rejected result nevertheless put that exact negative statement into the undocumented row's supporting-evidence array.

| Candidate cause                            | Diagnosis                                                                                                                                                                                                              |
| ------------------------------------------ | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| Ambiguous instructions                     | Confirmed: the old prompt asked each row to cite up to three resume excerpts and did not explicitly require empty evidence for undocumented rows.                                                                      |
| Conflicting examples                       | None: the old prompt contained no examples. No synthetic gold answers were sent to the provider.                                                                                                                       |
| Insufficient structured-output constraints | Confirmed: the old schema allowed 0–3 citations independently of classification. It admitted the rejected combination.                                                                                                 |
| Model/application schema mismatch          | Confirmed: the authoritative server validator already forbade evidence on an undocumented row. Structured Outputs enforced a weaker contract.                                                                          |
| Incorrect evidence interpretation          | The model used a truthful negative quotation as explanatory evidence. That is invalid in a field reserved for supporting qualification evidence; the React classification itself was correct after full-source review. |

Original synthetic failure row, preserved in the baseline:

```json
{
  "job": { "segmentId": "J004", "quote": "React experience preferred." },
  "classification": "undocumented",
  "evidence": [
    { "segmentId": "R003", "quote": "No JavaScript or React project listed." }
  ]
}
```

The server correctly rejected the entire report. No automatic relabeling, evidence stripping or weakening of that rejection was appropriate.
